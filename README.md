# gost732-2017

**Стили оформления документов по ГОСТ 7.32-2017 для Typst**

[![License](https://img.shields.io/github/license/bmstudents/typst-g7.32-2017?style=for-the-badge&color=2C2C2C&labelColor=1E1E1E)](https://github.com/bmstudents/typst-g7.32-2017/blob/main/LICENSE.md)

[![Typst](https://img.shields.io/badge/typst-0.14.2-2C2C2C?style=for-the-badge&logo=typst&labelColor=1E1E1E)](https://typst.app)

</div>

Пакет автоматического оформления расчётно-пояснительных записок, отчётов о НИР
и выпускных квалификационных работ по **ГОСТ 7.32-2017** и положению МГТУ им.
Баумана. Берёт на себя поля, шрифты, нумерацию, структурные элементы, рисунки,
таблицы, листинги, формулы, приложения и список источников — документ проходит
нормоконтроль **TestVkr** без правки оформления вручную. Двуязычный API: у всех
функций есть русские и английские имена.

## ■ Возможности

- ❖ **Полная разметка страницы** по ГОСТ: A4, поля 30/15/20/20 мм, Times New Roman 14 pt, красная строка 1.25 см, одинарный интервал, нумерация внизу по центру
- ❖ **Автоматические заголовки**: нумерация «1.1», разделы с новой страницы, автораспознавание структурных элементов (ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ, …) — по центру и капсом, без номера
- ❖ **Готовые структурные элементы**: реферат, содержание, введение, заключение, термины и определения, список источников
- ❖ **Содержание** одной командой: переносы длинных заголовков, лидер-точки, номера страниц справа, отступы по уровням
- ❖ **Рисунки, таблицы, листинги, формулы** с правильными подписями, сквозной нумерацией и разрывом через страницы («Продолжение таблицы N»)
- ❖ **Приложения**: автозаголовок «ПРИЛОЖЕНИЕ Х», собственная нумерация, подсчёт «Листов N», нумерация иллюстраций с буквой (А.1)
- ❖ **Термины и определения**: сбор по документу, сортировка, автоввод раздела
- ❖ **Счётчики для реферата**: число страниц/рисунков/таблиц/источников/приложений
- ❖ **Вставка готовых листов** (титул ТЗ, задание, скан) с полями ГОСТ, скрытым номером и исключением из сквозной нумерации
- ❖ **Неразрывная типографика**: связки «число + единица», диапазоны, модели, тире — не рвутся переносом строки
- ❖ **Список источников** по `gost-r-705-2008-numeric` с красной строкой

## ■ Установка

Пакет подключается из локального namespace Typst. Скопируйте каталог
`gost732-2017/` в директорию пакетов:

**Linux**
```bash
mkdir -p ~/.local/share/typst/packages/docs/gost732-2017/0.5.2
cp -r gost732-2017/* ~/.local/share/typst/packages/docs/gost732-2017/0.5.2/
```

**macOS**
```bash
mkdir -p "~/Library/Application Support/typst/packages/docs/gost732-2017/0.5.2"
cp -r gost732-2017/* "~/Library/Application Support/typst/packages/docs/gost732-2017/0.5.2/"
```

**Windows**
```powershell
mkdir "$env:APPDATA\typst\packages\docs\gost732-2017\0.5.2"
cp gost732-2017\* "$env:APPDATA\typst\packages\docs\gost732-2017\0.5.2\"
```

Либо используйте установщик из родственного пакета
[typst-bmstu](https://github.com/bmstudents/typst-bmstu) (`install.sh` / `install.ps1`).

## ■ Флаги инициализации

Передаются в `гост732-2017.with(...)`:

| Флаг | По умолчанию | Назначение |
|------|--------------|------------|
| `фича-переносы-слов` | `да` | Переносы слов по слогам |
| `фича-маленький-отступ-вокруг-таблиц` | `нет` | Поджать интервалы вокруг таблиц/листингов/рисунков |
| `фича-отступ-перед-подразделом` | `нет` | Пустая строка перед подразделом 2-го уровня (кроме первого) |
| `фича-неразрывные-величины` | `нет` | Неразрывные связки «число+единица», диапазоны, модели, тире |

Значения — `да` / `нет` (русские алиасы `true` / `false`).

## ■ Основные функции

Все функции имеют русское и английское имя.

| Назначение | Функция |
|------------|---------|
| Рисунок | `рис(данные, повернуто: false)[подпись]` / `img(...)` |
| Таблица | `таблица(table(…))[подпись]` / `table_figure(...)` |
| Ячейка таблицы (12 pt) | `ячейка(контент, размер: 12pt, выравнивание: none)` |
| Листинг кода | `листинг(raw(…))[подпись]` / `code(...)` |
| Содержание | `содержание()` / `table_of_contents()` |
| Раздел определений | `определения_обозначения_сокращения_раздел()` |
| Термин | `определение("ссылка", "определение")` / `definition(...)` |
| Приложение | `приложение(буква: "А", содержание: […], …)` / `appendix(...)` |
| Вставка листа | `вставить-лист(данные, скрыть-номер: false, повернуто: false, в-нумерации: true)` |
| Счётчики | `колво-страниц`, `колво-рисунков`, `колво-таблиц`, `колво-источников`, `колво-приложений` |
| Высота под рисунок | `размер(число-строк)` |

### Структурные заголовки

`реферат`, `содержание_заголовок`, `введение`, `заключение`,
`термины_и_определения`, `перечень_сокращений_и_ссылок`,
`список_исполнителей`, `список_использованных_источников_заголовок`,
`ненумерованный_заголовок(содержание: …, номер: …)[…]`.

## ■ Приложения

```typst
#show: приложение.with(
  буква: "А",
  содержание: [Техническое задание],
  собственная-нумерация: да,
  буква-в-иллюстрациях: да,
)
```

Заголовок «ПРИЛОЖЕНИЕ А», название в оглавлении, иллюстрации внутри
нумеруются «А.1», на титуле приложения печатается «Листов N».

## ■ Вставка готовых листов

```typst
#вставить-лист(image("titul.pdf"), скрыть-номер: да, в-нумерации: нет)
#вставить-лист(image("plakat.png"), повернуто: да)  // лист А1
```

`скрыть-номер` оставляет номер в текстовом слое (TestVkr его видит), но
печатает белым; `в-нумерации: нет` исключает лист из сквозной нумерации.

## ■ Тесты

В каталоге `tests/` — кроссплатформенный тест-харнесс: каждый тест это пара
`.typ` (компилируется пакетом) + `.py` (проверки по текстовому слою и
координатам через `pdftotext`). Покрыты все группы фич — **266 тест-файлов,
741 проверка**.

```bash
cd tests
python3 run_all.py        # параллельный прогон всего харнесса
python3 g0_smoke.py       # один тест
```

Бинари (`typst`, `pdftotext`) ищутся независимо от среды — через `PATH`,
переменные `TYPST_BIN` / `PDFTOTEXT_BIN` и типичные локации Linux/macOS/Windows.
